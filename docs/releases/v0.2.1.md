# Chroni v0.2.1 - 跨平台身份与完整产品打包

`v0.2.1` 是面向真实安装和后续应用商店提交的稳定性更新。它保留 Chroni 沙漏应用图标与完整蓝色桌面伙伴动画，修复 macOS 发布包误用沙漏占位桌宠、Intel 原生模块缺失和 Windows 将窗口显示为 Electron 的问题，并恢复信息完整的六工作区控制中心。

## 下载

| 平台 | 文件 |
| --- | --- |
| Windows 10/11 x64 安装版 | `Chroni-0.2.1-win-x64-setup.exe` |
| Windows 10/11 x64 便携版 | `Chroni-0.2.1-win-x64-portable.exe` |
| macOS 12+ Universal | `Chroni-0.2.1-mac-universal.dmg` |

请同时下载 `SHA256SUMS.txt` 核对完整性。正式 macOS 产物必须通过 Developer ID 签名和 Apple 公证，否则发布工作流会直接失败。

## 主要修复

- Windows 任务栏、标题栏、开始菜单和安装程序统一使用 Chroni 名称与现有沙漏图标。
- 标准发布包在构建前校验桌面伙伴素材，当前要求至少 100 帧且总体积不低于 5 MiB，避免再次退化为单张占位图。
- macOS Universal 包同时携带 Apple Silicon 与 Intel Canvas 原生模块；打包后会核对桌宠帧、双架构、Bundle 元数据、隐私清单、ASAR 完整性、签名和公证状态。
- macOS 菜单栏使用明暗模式自适应模板图标，日程浮层保持置顶；发布页不再回退到写死的旧版本安装包。
- 控制中心直接提供今日执行、学习任务、任务来源、执行 Agent、偏好设置和运行状态，窄窗口自动切换为无重叠图标工具栏。
- 运行状态新增公开隐私政策入口，保留完整开源许可和桌面伙伴素材说明。

## 商店准备

- 增加 Microsoft Store AppX 和 Mac App Store MAS 构建配置。
- 增加 Apple App Sandbox 权限与 `PrivacyInfo.xcprivacy`。
- 商店安装版由系统应用商店负责更新，不连接 GitHub 自更新通道。
- 商店发布仍需要维护者自己的 Partner Center / Apple Developer 身份、证书和人工审核。

## 升级说明

可以覆盖安装 `v0.2.0`。本地任务、日程、来源、证据、偏好和模型配置保留在用户数据目录中；卸载程序默认也不会主动删除这些数据。
