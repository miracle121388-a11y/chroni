# Chroni 0.2.5

本次更新修复材料识别、任务要求校验和本地语音转写问题。

- 改善文档、扫描 PDF、Office 内嵌图片与多页图片的读取，减少截止时间和提交材料遗漏。
- 修正中文日期、24:00、表格日期及日历时区解析；含糊时间继续交由用户确认。
- 加强模型抽取与规划的原文校验，避免混用不同任务的要求或改写数值、链接；无效结果回退本地规则。
- 改善简繁中文语音命令；本地 Whisper base 模型使用固定版本与 SHA-256 校验，下载中断可以重试，退出时释放引擎。
- 修复语音使用后退出可能残留进程的问题；先释放本地引擎和接口，再完成退出。
- 保留小童伙伴、关闭窗口后的菜单恢复入口、既有任务和排程。

应用继续免费，无广告或付费功能。原始语音不上传；联网模型仍需用户明确同意。

发布状态以 [应用商店发布记录](../store/README.md) 为准。
