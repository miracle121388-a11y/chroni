# Chroni v0.2.4 - 更准确的日程处理状态

`v0.2.4` 修正快速添加、文件导入、来源重识别和待确认操作中的加载文案。Windows 与 macOS 用户仍然无需 API Key、服务访问码或账号即可使用 Chroni 的完整模型能力。

## 下载

| 平台 | 文件 |
| --- | --- |
| Windows 10/11 x64 安装版 | `Chroni-0.2.4-win-x64-setup.exe` |
| Windows 10/11 x64 便携版 | `Chroni-0.2.4-win-x64-portable.exe` |

请同时下载 `SHA256SUMS.txt` 核对完整性。

## 文案与状态修正

- 直接输入文字时显示“正在理解日程”，不再错误显示“正在理解课程要求”。
- 文件导入和预览会按实际文件数量显示“正在识别/预览文件中的日程与任务”。
- 来源重识别、今日安排、回答保存和草稿放弃均使用各自准确的加载状态，多个按钮不会互相串词。
- 空状态、模型状态与隐私说明同时覆盖日程、任务和课程要求。
- 用户可见的错误、规划约束和建议不再使用 `DDL` 技术术语。
- 新增文案回归测试，阻止场景错误或含糊加载词重新出现。

## 模型与 macOS 说明

- DeepSeek 主密钥仍只保存在 Chroni 网关，安装包和本机状态不包含共享 API Key。
- 托管智能服务无需用户配置；达到公共额度、断网或服务暂时不可用时会回退本地规则。
- macOS 安装包暂未配置 Developer ID 签名和 Apple 公证，首次打开仍需按 Gatekeeper 提示手动允许。
