# Chroni v0.1.4 — 本地学习执行 Agent

Chroni 面向大学项目制学习，把通知、文档、表格、日历和截图中的课程要求，转成带来源的 Learning Mission、可编辑 TaskPlan、今日行动块、产出证据与阶段检查点。LLM 负责提出结构化候选，本地系统负责事实校验、风险与容量计算、状态变更、工具调用、Trace、Memory 和失败回退。

Chroni 不替学生完成作业。它解决的是从“看懂课程要求”到“持续执行、验证产出并调整下一步”的断层。

## 三分钟演示

1. 启动 Chroni，在控制中心进入 **GOAI 演示**并加载数据库课程项目；该路径无需 API Key。
2. 在 **学习任务**中核对来源、PDF/SQL 交付物、完成标准与里程碑。
3. 登记隔离合成证据与检查点，观察里程碑、进度和下一步同步变化。
4. 打开 **今日执行**和 **执行 Agent**，查看时间块、风险、覆盖率、工具结果与 `Ground -> Plan -> Act -> Verify -> Adapt` Trace。
5. 场景 B 只追问缺失截止；场景 C 保留冲突证据并等待用户裁决。
