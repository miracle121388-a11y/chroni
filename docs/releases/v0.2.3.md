`v0.2.3` 让 Windows 与 macOS 用户安装后无需 API Key、服务访问码或账号，即可使用 Chroni 的模型抽取、主动追问、TaskPlan 和 Agent 规划。

## 零配置模型能力

- 新安装默认启用 Chroni 智能服务，不要求用户配置任何凭据。
- DeepSeek 主密钥只保存在 Zeabur 网关环境变量中，不会写入桌面安装包、本机状态或客户端请求。
- 网关固定上游模型，并执行按来源网络和全局维度的公平限流、参数裁剪、上游超时及脱敏日志。
- 达到公共额度、断网或模型暂时不可用时，Chroni 自动使用本地规则继续处理，不会阻断任务导入。
- 高级用户仍可关闭联网模型，或切换到自己的 OpenAI-compatible API。

## macOS 钥匙串与安装提示

- 系统安全存储改为惰性初始化；托管模式没有客户端访问码，普通启动和使用 Chroni 智能服务都不会检查、创建或读取 `Chroni Safe Storage`。
- 只有用户主动保存自定义 API Key 时，Chroni 才会使用 Electron `safeStorage`，macOS 此时可能要求当前账户授权。
- 当前安装包尚未配置 Developer ID 签名和 Apple 公证，首次打开仍需按 macOS Gatekeeper 的安全提示手动允许；这与钥匙串授权是两件不同的事。

## 升级说明

可以覆盖安装旧版本。本地任务、日程、来源、证据和偏好会保留；旧版托管访问码会被安全丢弃且不会触发解密，已有用户主动关闭智能模型的选择保持不变。
