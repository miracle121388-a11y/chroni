# Chroni v0.2.0 — 学习执行 Agent 复赛版

Chroni 是面向大学项目制学习的 local-first 学习执行 Agent。它把课程通知、截图、文档和表格转成带来源的 Learning Mission，并把目标、交付物、完成标准、里程碑、今日行动、产出证据与阶段检查点连接为可追溯闭环。

Chroni 不替学生完成作业。模型负责提出候选，本地系统负责事实校验、约束、权限、工具执行、持久化、失败回退和状态变更。

## 三分钟体验

1. 安装并启动 Chroni，左键桌宠打开日程，进入控制中心。
2. 打开“GOAI 演示”，加载场景 A；该流程不需要 API Key 或网络。
3. 在“学习任务”核对来源、目标、交付物、完成标准和里程碑。
4. 登记隔离合成证据与阶段检查点，观察 Mission 进度和下一步变化。
5. 在“今日执行”查看 Agent 时间块，再到“执行 Agent”检查风险、覆盖率、工具结果与 Trace。
6. 使用场景 B 验证缺失截止时间的必要追问，使用场景 C 验证冲突时间必须由用户裁决。
7. 退出 Demo；Chroni 删除隔离合成状态并恢复主数据。

## 模型、隐私与边界

- 无 Key 模式可使用本地规则和隔离 Demo；复杂材料可选 Chroni 内测网关或用户自己的 DeepSeek OpenAI-compatible 配置。
- 原始文件先在本机解析/OCR，联网模型只接收完成抽取或规划所需的文本与结构化上下文。
- API Key 在系统支持时通过 Electron `safeStorage` 加密；内测 DeepSeek 主密钥不会下发到客户端。
- 证据文件正文和绝对路径不进入持久状态，默认导出会移除原文、标题、路径、凭据和敏感正文。
- 合成评测结果不等同于真实学生学习成效或真实 OCR/模型总体质量。
