# Chroni 模型使用方式

Chroni 提供三种真实可用的工作方式。它们共用同一套本地文件解析、来源证据校验、状态存储和失败回退。

| 方式 | 是否联网调用模型 | 凭据 | 适用场景 |
| --- | --- | --- | --- |
| 本地规则 | 否 | 不需要 | 标题、日期、时间较明确的通知 |
| Chroni 智能服务 | 是 | 用户无需凭据 | 下载后直接使用完整抽取与 Agent 规划 |
| 自定义 API | 是 | 用户自己的 API Key | 开发者、长期使用或需要自行控制服务商 |

## 本地规则

关闭智能模型、公共额度暂时用完或模型请求失败时，Chroni 会使用本地规则继续处理。PDF、DOCX、XLSX 和图片仍会先在本机解析或 OCR，不会因为没有模型而变成不可用的演示界面。

本地规则适合结构明确的输入：

```text
请在明天 20:00 前提交数据库作业 PDF，通过课程平台上传。
```

只有“尽快完成”“下次课前交”等模糊表达时，Chroni 才会要求确认，而不会编造日期。

## Chroni 智能服务

智能服务模式不要求用户申请 DeepSeek Key、Chroni 访问码或账号。维护者将 DeepSeek 主密钥保存在 Zeabur 环境变量中，桌面端不接收、不保存也不发送该密钥，只调用：

```text
https://api-getchroni.zeabur.app/v1/chat/completions
```

网关固定使用允许的 DeepSeek 模型，覆盖客户端提交的模型和思考模式，并执行请求体限制、来源网络限流、全局分钟/每日额度、并发限制、上游超时和脱敏日志。公共额度是公平使用保护，不承诺无限调用；达到额度时客户端自动使用本地规则。

### 安装版配置

1. 安装并启动 Chroni。
2. 直接导入材料；新安装已经选择并启用“Chroni 智能服务”。
3. 如需检查，进入“偏好 -> 高级 -> 智能模型服务”，点击“测试连接”。
4. 如需完全离线，关闭“启用智能模型”。

托管模式没有客户端凭据，因此不会因为使用公共智能服务而创建 `Chroni Safe Storage` 钥匙串项。只有用户切换到自定义 API 并保存自己的 Key 时才会使用系统安全存储。

## 自定义 API

选择“自定义 API”后，可填写 OpenAI-compatible Chat Completions 服务的 Base URL、模型 ID 和 API Key。DeepSeek 当前配置为：

```dotenv
CHRONI_LLM_ENABLED=1
CHRONI_LLM_MODE=custom
CHRONI_LLM_BASE_URL=https://api.deepseek.com
CHRONI_LLM_MODEL=deepseek-v4-flash
CHRONI_LLM_API_KEY=replace-with-your-own-key
```

源码开发者可复制根目录 `.env.example` 为 `.env`。优先级为：系统环境变量 > 项目 `.env` > 控制中心保存值。检测到环境变量时，界面不会回填凭据。

## 什么会发送

文件解析和 OCR 始终先在本机进行。启用任一联网模型模式后，Chroni 会发送完成当前抽取或规划所需的解析文本、任务元数据、来源摘要和已筛选的结构化偏好。长文档可能分块覆盖全文，二进制原文件不会作为文件直接上传。

托管网关只记录请求 ID、使用服务端密钥生成的来源网络摘要、状态码、耗时和 token 用量，不记录原始提示词、文件文本、原始 IP 或 DeepSeek Key。处理敏感材料前仍应阅读所用模型服务的隐私政策。

## 常见连接结果

| 提示 | 优先检查 |
| --- | --- |
| Chroni 智能服务暂时无法授权 | 客户端是否为最新版、网络是否拦截自定义请求头 |
| API Key 无效或无权限 | 自定义 Key 是否完整、账户是否开通 API |
| 模型名称不可用 | 自定义模式使用服务商当前模型 ID |
| 请求过于频繁或今日额度已用完 | 等待限流窗口，或联系维护者调整服务额度 |
| 连接超时 | 网络、代理、防火墙和 Base URL |
| 返回内容无法识别 | 重试；仍失败时保留本地规则结果并提交脱敏反馈 |

网关部署、额度和密钥轮换见[LLM 网关运维指南](../llm-gateway.md)。
