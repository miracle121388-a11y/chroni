# Chroni 真实产品 Demo 脚本

使用干净的 Windows 或 macOS 账户、GOAI `original` 构建和内置合成 Demo。必须录制真实运行的应用，不得在设计工具中重制交互或把剪辑伪装成实时结果。

## 录制准备

- 使用 `CHRONI_PET_ASSET_MODE=original` 构建，确认不包含 XIAOTONG 帧、二维码或未获赛事授权的第三方形象。
- 在控制中心打开 **GOAI 演示**，备份正式数据；关闭个人应用、通知和输入法候选记录。
- 使用 1920×1080、30/60 fps、H.264 MP4，鼠标可见，点击节奏清楚，中文字幕直接烧录并保留独立字幕文件。
- 遮挡用户名、用户数据路径、API 字段、Bearer Token、内测码、桌面私人内容和任何真实课程信息。
- 录制前运行 `pnpm run check` 与 `pnpm run eval:goai`，口播指标只使用本次真实输出。

## 演示用证据原则

- 如需现场选择文件，只使用仓库中明确标注为 synthetic 的演示产出，不使用原始课程材料冒充成果。
- 文件登记后只展示文件名、大小、关联交付物和短 SHA-256；不得展示本机绝对路径。
- “证据覆盖”只表示交付物有登记记录，不口播为“质量通过”或“作业正确”。
- 检查点的“完成”必须由演示者点击，不能描述成模型自动判定。

## 验收清单

- 每一帧产品画面来自当前真实 Chroni 构建。
- 场景内容明确标注为 synthetic，个人路径和密钥已遮挡。
- GOAI 视频不出现未获赛事书面授权的第三方形象。
- 口播指标与刚生成的报告完全一致，失败项和未测项没有被剪掉或改写。
- 任何加载/错误备用画面都有明显标识，不被呈现为实时行为。
- 最终 MP4 不依赖外部字体/编解码器，并在手机尺寸仍可读。
