# Chroni 真实产品 Demo 脚本

本脚本对应 `v0.2.4` 当前真实界面。演示使用附件中的合成示例，不把设计稿、剪辑备用画面或模型预写结果伪装成实时运行。

## 录制与现场准备

- 使用附件中的 Windows 安装包；首次启动后保持默认本地模式即可完成主链路。
- 只使用 `02_产品与Demo/示例材料` 中的 A/B/C 文件和产品内置 D 连续使用示例，不展示真实学生信息。
- 需要展示 DeepSeek 时再在“偏好”中填写临时测试配置；不在录屏中暴露 Key、访问码、Token 或本机路径。
- 关闭个人通知和私人应用。建议 1920×1080、30/60 fps，鼠标可见。
- 指标只引用附件中本次生成的评测和验证结果。

## 演示输入与预期

### A：明确任务

预期：直接生成明确任务与计划，不出现“缺少标题/截止时间”的阻断问题；可进入学习任务和今日执行。

### B：缺失截止时间

预期：保留已抽取的标题和交付物，只询问截止时间；回答后恢复同一草稿，不重复创建任务。

### C：来源时间冲突

预期：展示冲突来源和可选日期，不自动选择；用户确认后才写入事实状态。

### D：连续使用与动态干预（产品内置隔离示例）

预期：14 天合成回顾形成前后 7 天对比；9:30 的期末作业排在 9:00 社团初稿之前；两次历史未完成使期末作业触发 15 分钟重新启动。所有结果必须标注 synthetic。

## 验收清单

- 安装包可以在干净 Windows 账户启动，任务栏显示 Chroni 图标而不是 Electron；桌面伙伴显示蓝色动态桌宠，而不是放大的 Chroni 图标。
- A 的明确内容无需先回答问题；B 只问一个阻断项；C 保留来源并等待确认。
- D 的连续数据只存在于隔离示例命名空间；退出后正式数据不变，指标不得表述为真实学生成效。
- 学习任务、今日执行、每日回顾和桌宠入口均来自同一 Store，刷新或重启后数据仍在。
- 时间轴标题不被裁半；重叠任务分栏；每日回顾可切换日期且未保存内容不会误丢失。
- 模型不可用时给出规则回退和可读错误，不清空已解析内容。
- 所有示例明确标注为 synthetic；不展示个人数据、绝对路径、API Key 或 Token。
- 口播不把证据覆盖描述为作业质量，不把合成 benchmark 描述为真实学习成效。
