# GOAI 复赛 11 页路演结构

所有截图必须来自当前真实产品或明确标注的隔离合成 Demo。不得把设计稿、未来功能或未授权数据当成已实现证据。

## 1. 封面：Chroni 学习执行 Agent

- 主标题：**让课程要求真正落到执行与证据**
- 副标题：面向大学项目制学习的本地学习执行 Agent。
- 核心句：不替学生完成作业，而是把课程要求转化为可执行、可验证、可调整的学习过程。
- 画面：Learning Mission 真实产品截图 + 原始自研沙漏标识；桌宠作为环境入口出现，但不抢主叙事。
- 评委应记住：Chroni 的类别是 learning execution Agent，不是 DDL 工具或桌宠应用。

## 2. 问题：学习断在“知道”和“做到”之间

- 课程要求分散在通知、截图、PDF、文档、表格和日历中。
- 日历只记录时间，聊天助手通常只给一次性答案；二者都没有持续维护“要求 → 路径 → 行动 → 证据 → 调整”。
- 项目制学习的三段断层：要求到路径、计划到真实时间、行动到可检查产出。
- 画面：一个数据库项目的多来源合成材料，标注“合成演示数据”。
- 禁止：没有授权研究时，不使用市场比例、成绩提升或学校覆盖数字。

## 3. 立意：AI 不代写，AI 负责执行支架

- Chroni 的教育价值不是生成答案，而是帮助学生形成目标意识、过程管理、证据意识和阶段反思。
- 原始课程材料不计为成果证据；时间块结束不等于任务完成；模型无权自行宣布完成。
- 画面：对比“生成答案”与“建立执行闭环”，突出用户控制权。
- 评委应记住：这是与教育诚信相容的 Agent 设计。

## 4. 核心产品：Learning Mission

- 一条 Mission 同时保存来源、目标、交付物、完成标准、里程碑、当前行动、产出证据、检查点与风险。
- TaskPlan 变化会同步里程碑；检查点可绑定具体里程碑并回写步骤状态和任务进度。
- 文件证据由主进程流式计算 SHA-256，状态不保存绝对路径和文件内容。
- 画面：`docs/assets/chroni-learning-mission-v0.2.0.png`，使用隔离演示数据。

## 5. 三分钟真实 Demo：从材料到适应性下一步

- 场景 A：数据库课程项目 → Learning Mission → 今日时间块 → 文件/说明证据 → 检查点 → Agent Trace。
- 场景 B：材料缺失截止时间，只问一个阻断执行的问题。
- 场景 C：多来源截止冲突，保留证据并由用户裁决。
- 演示最后退出 Demo，证明合成状态和主 Store 隔离。
- 画面：GOAI Demo、学习任务、今日执行、执行 Agent 四个真实界面连续录屏。

## 6. Agent 闭环：Ground → Plan → Act → Verify → Adapt

- **Ground**：解析/OCR，模型提出候选，本地核验来源、日期、冲突与必填字段。
- **Plan**：生成可编辑、可版本化的目标、步骤、依赖、交付物、完成标准和缓冲。
- **Act**：按风险、slack、容量和真实可用时间执行排程、提醒与持久化工具。
- **Verify**：读取用户登记的产出、实际投入、受阻原因和阶段状态。
- **Adapt**：重算风险、覆盖缺口与下一步，保留用户确认权和规则回退。
- 画面：技术架构图 + 一次实际 Trace。

## 7. 技术深度：模型提出，本地系统掌权

- 多格式接收与本地 OCR；OpenAI-compatible / DeepSeek 语义增强。
- 严格 schema、来源证据、条件/冲突检测、去重与幂等追问恢复。
- 版本化 TaskPlan、容量调度、重叠时间块分栏、历史与未来计划。
- typed IPC、context isolation、回环 Bearer API、OS 安全存储、失败回退。
- Learning Mission 同步器、SHA-256 证据、结构化 Trace 和默认脱敏导出。
- 不讲“多 Agent”故事；Chroni 是一个有明确工具和状态边界的混合式 Agent。

## 8. 评测：把成功和失败一起展示

- 离线评测：60 条固定时钟、零模型调用的合成案例，报告包含数据集哈希、字段指标、追问、回退、p95 和失败样例。
- 工程验证：类型检查、Node 测试、Electron main/React renderer 生产构建、站点检查与跨尺寸截图。
- Learning Mission 验证：来源同步、里程碑回写、证据/检查点持久化、路径不入状态、删除级联和 API 鉴权。
- 只展示 `reports/latest.json` 和最终测试输出中的真实值；不得口头补齐未测指标。

## 9. 安全、隐私与教育边界

- Local-first，无隐藏分析；模型关闭时不请求模型服务。
- 二进制材料先在本机解析/OCR，启用模型后只发送必要文本与结构化上下文。
- Key 不进入普通状态和证据导出；证据正文、来源全文、路径默认脱敏。
- 明确合成数据、未成年人/学生数据最小化、用户删除权和人工最终确认。
- 复赛安装包使用经清单校验的 product/xiaotong 动态桌宠；完整许可证、附加条款、回链、About 与非商业/商业边界单独披露。

## 10. 开源价值：可复用的执行 Agent 参考实现

- MIT 自研代码、能力契约、typed IPC/API、合成场景、评测 CLI、Trace、威胁模型、CI 与双端打包流程。
- 可复用对象不是桌宠图片，而是“模型候选 + 本地事实权 + 工具闭环 + 证据反馈”的工程架构。
- 邀请社区贡献解析器、课程平台适配、无障碍、日历连接器和授权评测集。
- 不声称已有大型社区或生态。

## 11. 路线与诉求：从可复现产品到授权试点

- P1：真实图片 OCR 与显式 opt-in 模型评测、解析器/压缩包安全加固、签名与公证。
- P2：在知情同意下开展小规模课程项目试点，测量要求理解、计划执行、证据留存与阻塞恢复，不先承诺成绩提升。
- P3：课程平台与日历适配、团队协作、教师可选的结构化任务模板和隐私分级。
- 诉求：授权试点场景、安全/教育评测指导、分发签名资源、可公开的匿名评测材料。
- 结尾：**Chroni 不替学生走完路，它让每一步更清楚、更可执行，也更值得回看。**
