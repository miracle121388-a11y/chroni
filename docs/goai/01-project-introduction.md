# Chroni 项目介绍

## 项目定位

**Chroni：面向大学项目制学习的本地学习执行 Agent。**

一句话价值：**不替学生完成作业，而是把课程要求转化为可执行、可验证、可调整的学习过程。**

## 我们重新定义的问题

学生收到的不是一条干净的待办，而是一组散落在群通知、截图、PDF、表格、日历和自然语言里的约束。传统日历解决“什么时候截止”，聊天助手解决“这段话说了什么”，但项目制学习还有三段断层：

1. **从要求到路径**：学生知道要交什么，却不知道先做什么、完成到什么程度。
2. **从计划到行动**：计划没有进入真实可用时间，依赖、风险与容量没有持续更新。
3. **从行动到证据与反思**：时间块结束不代表学习完成，过程缺少可检查产出、阻塞反馈和下一步调整。

Chroni 解决的不是 DDL 记录，而是上述“理解、执行、验证、回顾、调整”的连续性问题。

## 目标用户与首个场景

目标用户是承担课程项目、实验报告、团队交付和多阶段作业的大学生。首个完整演示场景选择数据库课程项目，因为它同时具备：多份要求、明确交付物、步骤依赖、可检查产出、实际投入差异和截止约束，能够真实检验 Agent 闭环，而不只是展示聊天回答。

## 核心产品对象：Learning Mission

每条来源驱动的课程任务会形成稳定的 Learning Mission，包含：

- 原始来源、来源片段与规划来源；
- 学习/交付目标、交付物与完成标准；
- 来自 TaskPlan 的里程碑、估时、依赖与当前行动；
- 用户登记的产出文件元数据、SHA-256 或文字证据；
- 与里程碑绑定的“顺利、受阻、完成”检查点、实际投入与反思；
- 根据截止、剩余工作、证据覆盖和阶段反馈计算的进度与风险。

原始课程材料不会被计为成果证据，模型不能自行宣布任务完成。Chroni 记录的是执行支架与过程证据，不是自动学术评分。

## Agent 闭环

```text
Ground：从课程材料锁定事实、边界与不确定性
Plan：形成目标、交付物、完成标准、里程碑和时间预算
Act：把当前步骤排入真实可用时间并触发本地工具
Verify：登记产出、实际投入、阶段状态和阻塞
Adapt：重算风险、下一步和日程，保留用户确认权
```

独立“每日回顾”把当天活动轨迹、完成率、计划/实际投入、自动摘要、个人记录和未完成项顺延保存在日期维度。它让 Agent 不只负责排出今天，还能把当天发生了什么反馈给下一轮规划。

排序不再只看截止先后。Chroni 同时读取学业后果、截止距离、当前进度、剩余工作量和最近 14 天计划执行记录；一次未完成触发 25 分钟恢复推进，连续未完成触发 15 分钟重新启动，近 7 天持续低执行则在用户设定上限内收敛下一轮容量。每日回顾同步显示前后 7 天任务完成率、执行效率、计划未完成率和节奏平衡，并明确这些是本机行为代理指标，不是学习成绩或心理诊断。

大模型负责复杂语义理解和结构化候选，本地确定性系统负责文件解析/OCR、来源核验、日期与 schema 校验、冲突处理、计划版本、容量调度、证据哈希、状态变更、持久化和失败回退。这不是“模型回复 + UI 外壳”，而是模型能力被本地工具和可审计状态约束的混合式 Agent。

## 桌宠为什么必要

桌宠不是独立卖点，而是 Agent 的环境式交互层：学生可以把材料直接拖给它，处理状态通过动作和短气泡反馈，阶段风险通过低打扰提醒出现，左键立即返回日程。它把需要频繁打开应用的管理动作，降低为桌面上的自然入口，同时受勿扰、频率、去重和用户关闭权控制。

## 当前完成度与开源价值

仓库包含可运行的 Electron 产品、Windows/macOS 交互、多格式接收与 OCR、DeepSeek-compatible 模型配置、TaskPlan/版本管理、Learning Mission、证据与检查点、每日时间轴、独立每日回顾、学习执行 Agent、主动追问恢复、行为记忆、回环 API、更新与发布工作流、脱敏证据导出、自动化测试和 60 条合成评测。

可复用资产包括能力契约、typed IPC/API、合成场景、评测脚本、Trace 与安全/IP 文档。项目不声称真实部署规模、学校合作或学习成绩提升。

## 报名简介（500 字以内）

Chroni 是面向大学项目制学习的本地学习执行 Agent。它不替学生完成作业，而是把散落在群通知、截图、PDF、文档、表格和日历中的课程要求转化为可追溯的 Learning Mission：目标、交付物、完成标准、里程碑、今日行动、产出证据与阶段检查点。大模型负责理解复杂语义并提出结构化候选，本地系统负责解析/OCR、来源与日期校验、冲突处理、计划版本、容量调度、证据哈希、状态变更和失败回退；只有阻断执行的信息才会追问。学生登记真实产出和“顺利、受阻、完成”反馈后，Agent 会重新计算风险与下一步；独立每日回顾进一步保存活动轨迹、总结和未完成项顺延。桌宠是常驻桌面的低打扰入口。无 API Key 时，结构明确的任务仍可离线运行。项目开放能力契约、合成数据、60 条可复现评测、结构化 Trace 和脱敏证据导出。

## 100 字版本

Chroni 将课程材料转成有来源的 Learning Mission，并把目标、里程碑、今日行动、产出证据和阶段反馈串成执行闭环。模型只提候选，本地系统掌握事实、工具、状态、回退与隐私，不代写、不虚构完成。

## One sentence

Chroni turns course requirements into an evidence-led, adaptive learning execution loop without doing the coursework for the student.
