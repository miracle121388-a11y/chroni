# Chroni v0.2.0 复赛更新说明

更新日期：2026-08-25
提交赛道：GOAI 2026 无界应用赛道复赛

## 1. 本轮更新结论

Chroni 已从 `v0.1.4` 的桌面 Deadline Agent，升级为**面向大学项目制学习的本地学习执行 Agent**。DDL 仍是可靠的任务触发器，但产品不再止于“记住截止时间”，而是围绕学习目标和可验证产出持续完成：

```text
材料输入 → 来源与意图确认 → Learning Mission → TaskPlan
→ 今日执行 → 产出证据与阶段检查点 → 风险重算与下一步调整
```

产品坚持“不替学生完成作业”。模型负责提出结构化候选，本地系统负责事实校验、约束、权限、持久化、工具执行、失败回退和状态变更；桌宠是低打扰的环境交互入口。

## 2. 与 v0.1.4 的主要差异

| 维度 | v0.1.4 | v0.2.0 复赛版 |
| --- | --- | --- |
| 产品中心 | DDL、TaskPlan 与提醒 | Learning Mission 与学习执行闭环 |
| 规划对象 | 单个截止任务 | 目标、交付物、完成标准、里程碑和今日行动 |
| 验证方式 | 用户勾选完成 | 说明证据、本地文件 SHA-256、阶段检查点与人工确认 |
| Agent 行为 | 抽取、追问、拆解、排程 | Ground → Plan → Act → Verify → Adapt |
| 冲突处理 | 字段待确认 | 来源级证据、冲突安全延迟、用户裁决与 Trace |
| 演示方式 | 用户准备材料 | 无 Key 隔离 GOAI Demo，含成功与失败分支，可退出并清理 |
| 评测证据 | 通用回归测试 | 60 条固定时钟合成案例、逐例结果、runner、schema 与关键测试 |
| 提交材料 | 安装包与常规文档 | 更新版方案、Demo、工程复现、评测、安全合规、可运行产品六部分 |

## 4. 可核验更新

- 新增 Learning Mission：来源、目标、交付物、完成标准、里程碑、进度、风险、证据和检查点统一建档。
- 新增产出证据与阶段检查点：支持本地文件流式 SHA-256、变更检测、里程碑回写和下一步调整。
- 今日执行时间轴支持真实时长、缩放、重叠分栏、颜色区分、拖动调整和跨日回顾。
- 主动追问改为“先形成基础计划，再补充完善”；只有必需字段缺失或来源冲突时才阻断。
- 新增无 Key 隔离 Demo、60 条离线评测、默认脱敏证据导出与结构化 Trace。
- 发布页、README、安装包、版本说明与复赛附件统一到 `v0.2.0`。

## 5. 已验证结果与边界

当前 60 条固定时钟合成案例离线成功率为 100.0%，任务 F1 为 100.0%，标题归一化准确率为 95.5%，交付物 F1 为 83.9%。这些指标只证明**合成数据上的确定性系统闭环**，不代表真实学生学习成效、DeepSeek 总体准确率或真实图片 OCR 总体性能。

项目尚未声称拥有学校合作、生产用户、学习成绩提升、商业代码签名或 macOS 公证。真实课程材料研究需经过授权、匿名化、最小化采集和可撤回流程。
