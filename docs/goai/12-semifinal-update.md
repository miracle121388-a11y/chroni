# Chroni v0.2.4 复赛更新说明

更新日期：2026-09-02
提交赛道：GOAI 2026 无界应用赛道复赛（AI+教育）

## 1. 对比基线

本说明严格以初版 `v0.1.4` 为对比基线：

- 初版源码：tag `v0.1.4`，commit `225f63be9076efd60ff014bcabb837e93a510fa0`，2026-07-15 发布。
- 当前版本：`v0.2.4`，以最终附件根目录 `PROJECT_VERIFICATION.json` 记录的 `main` commit 为准。
- 两版之间的差异可通过 `git diff v0.1.4..<提交 SHA>` 独立核验。

初版已经具备多格式抽取、TaskPlan、每日时间轴、Deadline Agent、桌宠提醒和本地存储。本轮不是把这些既有能力重新包装，而是在它们之上补齐“目标、过程、证据、反馈、复盘”五个环节，使产品从 DDL 管理器进入可持续的学习执行闭环。

## 3. 当前完整闭环

```text
TXT / PDF / DOCX / XLSX / ICS / 图片 / 手工输入
→ 本地解析与 OCR
→ 可选 DeepSeek 结构化候选
→ 来源、日期、冲突、重复与 schema 本地校验
→ 智能整理与必要时单问题确认
→ Learning Mission + 版本化 TaskPlan
→ 今日执行时间块 + 桌宠/系统提醒
→ 产出证据 + 里程碑检查点
→ 每日回顾 + 未完成项顺延
→ 风险、计划和下一步调整
```

模型只负责语义候选与可选规划建议。事实写入、时间约束、工具调用、完成状态、证据和持久化均由本地系统及用户确认控制。模型失败、超时或输出非法 JSON 时，系统保留本地规则路径与可解释回退。

## 5. 竞争优势

1. **不是聊天壳**：从材料输入到本地工具执行、证据反馈和日程调整形成连续状态机。
2. **不替学生代写**：关注执行支架、过程证据和自我调节，模型不能评分或宣告完成。
3. **桌面环境入口**：桌宠承接拖放、反馈与提醒，控制中心承担复杂规划，减少学习任务切换成本。
4. **Local-first 事实权**：文件先在本机解析，Key 使用系统安全存储，模型输出始终经过本地校验。
5. **真实可运行而非概念稿**：提供 Windows 安装包、公开源码、真实截图、测试、benchmark 和可重现命令。
6. **可复用工程资产**：能力契约、typed IPC/API、评测 runner、Trace/证据格式、威胁模型和跨平台发布工作流均可迁移。
7. **低门槛交付**：公开下载页、Release 直链和托管模型入口降低 GitHub、Node.js 与 API Key 的使用门槛。

## 6. 事实边界

- 60 条评测使用固定时钟和合成数据，证明的是确定性系统行为，不等同于真实学生学习成效。
- 当前报告不能代表 DeepSeek 在所有课程材料上的总体准确率，也不能代表真实图片 OCR 总体性能。
- 项目没有声称学校合作、生产用户规模、成绩提升、收入、融资、自研基础模型或比赛结果。
- Windows 赛事安装包未使用商业 Authenticode 证书；macOS 产物需由 macOS runner 构建并完成正式签名/公证后再公开分发。
- 教育建议用于学习过程辅助，不替代教师、学校或专业机构的评价。
- 动态桌宠素材按 Apache-2.0 与项目附加条款署名分发；当前不声称具有独立商业授权，商业发行前必须取得书面许可或替换素材。

## 7. 最终提交原则

正式附件 `Chroni_GOAI_2026_复赛最终提交.zip` 只保留评委需要的方案、真实产品证据、演示输入、复现材料、评测、合规文件和可安装产品。历史提示词、开发过程稿、营销素材、缓存、Node 依赖、个人配置和 API Key 均不进入附件。

## 8. 评委反馈后的专项增强

- 日程、Agent 和未来 7 天预排统一使用“学业语境 + 截止 + 进度 + 工作量 + 历史执行”排序，解决接近 DDL 只按时间先后的问题。
- 今日与未来预排会避开手动课程、会议和重复日程，在真实可用时间缝隙中拆分工作块。
- 大模型提示与本地意图校验支持聊天、段落、项目符号和表格语义；时间仍必须由原文证据确定。
- 历史未完成工作块不再被重排覆盖；一次未完成触发 25 分钟恢复推进，两次及以上触发 15 分钟重新启动。
- 每日回顾新增前后 7 天任务完成率、执行效率、计划未完成率和节奏平衡；持续低执行会在用户容量上限内收敛下一轮计划。
- 新增隔离的 14 天合成连续使用案例和对应自动化测试。详细口径与事实边界见 [13-judge-feedback-optimization.md](./13-judge-feedback-optimization.md)。
