# Chroni 一页纸

## 一句话

**Chroni 是面向大学项目制学习的本地学习执行 Agent：不替学生完成作业，而是把课程要求转化为可执行、可验证、可调整的学习过程。**

## 问题

课程项目不是一条干净待办。要求散落在通知、截图、PDF、文档、表格和日历中；即使学生知道截止时间，仍要跨越“理解要求、设计路径、进入真实时间、留下可检查产出、根据阻塞调整”五个环节。日历只管理时间，一次性聊天回答停在建议层，二者都没有持续维护这条学习执行链。

## 解决方案

Chroni 把每项来源驱动的课程任务组织成 Learning Mission：

```text
Ground 来源与边界
→ Plan 目标、交付物、完成标准和里程碑
→ Act 今日可执行时间块
→ Verify 产出证据、实际投入和阶段检查点
→ Adapt 风险、阻塞与下一步
```

DDL 是触发器，桌宠是低打扰的环境入口，Learning Mission 和本地工具闭环才是产品核心。

## 教育价值

- **反代写**：不生成可冒充学生完成的作业，不把来源材料或时间块结束当成成果。
- **过程可见**：目标、完成标准、阶段产出和阻塞在同一任务档案中，支持自我监控与回顾。
- **适应现实**：实际投入、受阻原因和证据覆盖会影响后续风险与排程，不要求学生机械服从初始计划。
- **用户掌权**：模型只能提出候选；任务创建、冲突选择、完成状态、证据与记忆均由本地规则和用户控制。

## 技术亮点

1. **混合式事实权**：多格式本地解析/OCR + 可选 DeepSeek/OpenAI-compatible 理解；来源、日期、schema、冲突、重复与状态转换全部在本地校验。
2. **可执行 Agent**：版本化 TaskPlan、依赖与估时、风险/slack/容量调度、本地排程/提醒/持久化工具、结构化 Trace 和规则回退。
3. **证据驱动反馈**：产出文件由主进程流式计算 SHA-256，只保存元数据；检查点绑定里程碑并同步计划步骤、进度与风险。
4. **Local-first 安全**：renderer 无 Node 权限、typed IPC、Bearer 回环 API、OS 安全存储、默认脱敏导出、合成 Demo 隔离与原始资产赛事构建。

## 已实现产品

可运行 Electron 桌面端；Windows/macOS 窗口与桌宠交互；TXT/PDF/DOCX/XLSX/ICS/图片接收与 OCR；主动追问恢复；TaskPlan；Learning Mission；文件/说明证据；阶段检查点；日/多日/周/月时间轴；学习执行 Agent；行为记忆；本地 API；更新和双端打包流程；无 Key 隔离 Demo；自动化测试与 60 条合成评测。

项目不声称真实用户规模、学校合作、学习成绩提升、收入、融资或自研基础模型。

## 开源价值

MIT 自研代码、能力契约、typed IPC/API、合成示例、评测 CLI 与 gold labels、Trace/证据格式、威胁模型、IP 清单、CI 和跨平台发布工作流，为“模型候选 + 本地事实权 + 工具执行 + 证据反馈”的个人 Agent 提供可复用参考实现。
