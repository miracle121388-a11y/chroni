## 简短描述

把课程通知、文档、截图与项目要求转化为有依据的学习任务、今日行动和成果证据。

## 完整描述

Chroni 是一款面向项目制学习的本地优先桌面应用。它从 TXT、Markdown、PDF、DOCX、XLSX、ICS 和常见图片中识别目标、交付物、截止时间与限制，并将一条课程要求组织为可执行、可验证、可调整的 Learning Mission。

学习任务不仅包含标题和日期，还可以持续记录目标、完成标准、里程碑、风险、下一步、实际投入与产出证据。每日执行视图根据任务时长、依赖、固定日程和可用时间生成现实的工作块，支持日、多日、周、月视图和手动重排。

独立的“每日回顾”栏目按日期整理完整活动轨迹、完成率、投入时长和待延续事项。系统会根据当天真实状态生成可编辑总结，个人记录与历史表现保存在本机，过去和未来的计划都可随时查看。

桌面伙伴提供轻量入口：点击查看日程，拖入文件开始识别，并用动作、短气泡和系统通知呈现理解、规划、提醒与完成状态。控制中心关闭后，任务和提醒仍会在本机继续工作。

Chroni 默认把任务、计划、偏好和执行记录保存在本机，不提供广告追踪或默认云同步。新安装默认启用无需 API Key、访问码或账号的 Chroni 智能服务；只有完成当前抽取或规划所需的文本会发送到模型服务，用户也可以随时关闭联网模型。

Chroni 不替用户完成或提交作业，也不会自动宣布学习成果已经达标。模型提出结构化候选，本地系统负责来源核验、容量计算、状态变更、持久化和失败回退，最终控制权始终属于用户。

## 截图顺序

1. 首次启动：空数据状态中的“导入任务”和“新建日程”入口。
2. 今日执行：时长正确的时间块、重叠分栏、缩放和智能安排。
3. Learning Mission：目标、交付物、完成标准、里程碑与产出证据。
4. 智能整理：一句话与多格式材料在同一入口完成识别、建档和今日安排。
5. 每日回顾：独立栏目同屏展示回顾日历、历史记录、完成指标、活动轨迹和个人整理。
6. 桌面伙伴：真实桌宠窗口与今日计划同屏，展示待机、阅读、提醒和完成状态的轻量入口。
