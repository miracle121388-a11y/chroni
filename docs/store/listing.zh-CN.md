## 简短描述

把课程通知、文档、截图与项目要求转化为有依据的学习任务、今日行动和成果证据。

## 完整描述

Chroni 是一款面向项目制学习的本地优先桌面应用。它从 TXT、Markdown、PDF、DOCX、XLSX、ICS 和常见图片中识别目标、交付物、截止时间与限制，并将一条课程要求组织为可执行、可验证、可调整的 Learning Mission。

学习任务不仅包含标题和日期，还可以持续记录目标、完成标准、里程碑、风险、下一步、实际投入与产出证据。每日执行视图根据任务时长、依赖、固定日程和可用时间生成现实的工作块，支持日、多日、周、月回顾和手动重排。

桌面伙伴提供轻量入口：点击查看日程，拖入文件开始识别，并用动作、短气泡和系统通知呈现理解、规划、提醒与完成状态。控制中心关闭后，任务和提醒仍会在本机继续工作。

Chroni 默认把任务、计划、偏好和执行记录保存在本机，不提供广告追踪或默认云同步。大模型能力完全可选；启用后，只有完成当前抽取或规划所需的文本会发送到所配置的模型服务。

Chroni 不替用户完成或提交作业，也不会自动宣布学习成果已经达标。模型提出结构化候选，本地系统负责来源核验、容量计算、状态变更、持久化和失败回退，最终控制权始终属于用户。

## 截图顺序

1. Learning Mission：目标、交付物、完成标准、里程碑与产出证据。
2. 今日执行：时长正确的时间块、重叠分栏、缩放和智能安排。
3. Agent 工作台：覆盖率、风险、今日工作块和下一步。
4. 任务来源：多格式文件、OCR 状态与来源依据。
5. 桌面伙伴：待机、阅读、规划、提醒与完成状态。
