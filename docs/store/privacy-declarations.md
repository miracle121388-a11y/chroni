# Chroni 商店隐私申报基线

本文件用于保持 App Store Connect、Microsoft Partner Center、公开隐私政策和应用实际行为一致。提交人应逐项照此填写，不应仅凭界面文案判断。

## 数据边界

- 任务、来源文本、计划、每日安排、偏好、执行记录和证据元数据默认保存在本机，Chroni 不提供账号、广告追踪或默认云同步。
- 关闭 LLM 时，不会把任务内容发送到模型服务。
- 启用托管模型或自定义 OpenAI-compatible 模型后，完成抽取或规划所需的文本、来源名称和时间上下文会离开设备。
- 托管网关转发请求并执行限流。它不记录提示词正文，但运维日志可能包含请求标识、服务凭据标识、状态、耗时和 token 数；上游模型服务的数据保留规则同时适用。
- Chroni 不收集精确位置、联系人、照片图库、支付信息、健康数据、浏览历史或广告标识，不进行跨应用追踪。

## App Store Connect

按当前可选模型能力保守申报以下数据类型，目的均为 **App Functionality**，不得勾选 Tracking：

| Apple 数据类型 | 是否可能收集 | 是否可能关联 | 原因 |
| --- | --- | --- | --- |
| User Content -> Other User Content | 是 | 是 | 启用模型后发送解析文本和规划上下文；自定义服务可通过用户自己的服务账户关联。 |
| Identifiers -> User ID | 是 | 是 | 托管模型使用可撤销服务凭据标识做鉴权与限流，不代表 Chroni 账号。 |
| Usage Data -> Other Usage Data | 是 | 是 | 托管服务可能记录请求状态、耗时和 token 数。 |

不得申报广告、第三方广告、开发者广告、分析、产品个性化或其他跟踪目的。`PrivacyInfo.xcprivacy` 必须与以上基线一致。

## Microsoft Partner Center

- 隐私政策网址：`https://getchroni.zeabur.app/privacy.html`
- 声明应用处理用户主动提供的文本与文件内容，用于本地任务管理和可选模型理解。
- 声明应用使用互联网连接访问用户选择的模型服务、公开帮助链接和版本信息。
- 声明本地回环 API 只监听 `127.0.0.1`，不提供局域网服务。
- 不声明广告、第三方跟踪、数据出售或未实现的账号删除流程。

## 留存与删除

- 本地数据保留到用户主动删除 Chroni 数据目录；应用内“运行状态”可打开该目录。
- Chroni 托管网关应用代码不建立提示词数据库；部署平台日志和 DeepSeek 的留存由各自配置与政策决定。
- 用户可关闭 LLM、移除访问码或 API Key、撤销托管访问码，并在完全退出后删除本地数据。
- 若托管网关的日志字段、留存配置或上游服务发生变化，必须先更新公开隐私政策和本申报，再提交新版本。
