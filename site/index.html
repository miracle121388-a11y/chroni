Learning Mission

一条课程任务，
不应只剩一个截止时间。

Chroni 把目标、交付物、完成标准、执行里程碑、真实投入和产出证据放进同一份任务档案。计划发生偏差时，下一步会随检查点重新计算。

Evidence-led loop

  1. 01
    Ground

    从原始课程要求锁定事实与边界。

  2. 02
    Plan

    形成目标、依赖、里程碑与完成标准。

  3. 03
    Act

    把可执行步骤安排进真实可用时间。

  4. 04
    Verify

    登记成果与实际投入，识别阻塞和偏差。

  5. 05
    Adapt

    保留用户控制权，重新计算下一步。

Chroni 不替学生生成最终答案。 它帮助学生看清要求、组织过程、留下证据，并对自己的学习负责。

Learning Execution Agent

Agent 不止给建议。
它观察、行动，也验证。

任务是否有依据、里程碑是否被阻塞、剩余工时够不够、今天还能安排多少，Agent 会在每次行动前后完成复查。

  • 01综合学习目标、截止时间、依赖和每日容量
  • 02以检查点、成果证据和 Trace 验证执行结果
  • 03模型不可用时仍有本地规则与安全回退

Before you install

开始前可能关心的事。

一定要配置自己的大模型 API Key 吗？

不需要。内测期间可使用 Chroni 内测访问码连接托管模型服务；也可以切换到自定义 API，使用自己的 DeepSeek 等兼容服务。

文件会上传到 Chroni 服务器吗？

文件解析、PDF 文本提取和图片 OCR 在桌面端完成。开启智能模型时，当前任务所需的提取文本会发送给所选模型服务，原始文件不会进入 Chroni 网关。

Windows 和 macOS 的功能一致吗？

两端共享 Learning Mission、学习执行 Agent、每日计划、成果证据和文件理解能力，并分别适配窗口、桌宠拖动、托盘与系统通知交互。

新版本怎样更新？

本页会通过 GitHub Releases 自动读取最新正式版本。发布完成后，下载按钮会自动指向新的安装包。
