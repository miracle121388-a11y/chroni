01

快速开始

安装后可直接新建日程，或把 TXT、Markdown、PDF、DOCX、XLSX、ICS 和常见图片拖入“智能整理”。新安装默认使用本地规则；如需联网语义理解，请在“偏好 → 高级”主动开启并确认数据发送说明。

查看快速开始 安装与安全提示

02

先做这三项检查

确认系统时间与时区正确；在“运行状态”检查本地解析、OCR 与模型状态；模型不可用时关闭智能模型，验证本地规则是否仍可处理明确日期的内容。

若应用无法正常启动或导入，请保留 Chroni 版本、macOS 版本、错误原文和最小复现步骤，不要附上真实课程文件、API Key 或本地用户名路径。

03

提交问题

公开功能问题请通过 GitHub Issues 提交。建议写明预期结果、实际结果、复现步骤和已脱敏截图。

提交功能或故障问题 查看版本与更新

04

隐私与安全

隐私边界与删除方法见公开隐私说明。API Key 泄露、任意代码执行、鉴权绕过或数据泄露请使用私密安全报告，不要创建公开 Issue。
