# 发布前工程审核

综合 release-review 的安全、隐私、UX、分发、网络/API 五类检查，按实际平台与变更范围应用。该审核验证应用本身，与 ASC 资料验证互补。首次发布做基线检查；更新聚焦差异、数据迁移、SDK/权限变化和关键路径回归。

## 取证和分级

先发现工程/入口/targets/extensions、发行渠道、依赖和后台，再读相关代码和最终产物。搜索结果只是候选问题，不是漏洞证明；写出触发路径或实际失败，不能仅凭出现某字符串断言不合规。

每个发现记录：优先级、文件行或产物位置、触发条件、用户影响、依据、最小修复、验证方法。审核规则涉及要求时链接当前 Apple 来源；区分“明确要求”“实际缺陷”“改善建议”。记录未执行和不适用项及原因。

- **阻塞**：身份/签名错误、核心功能崩溃或丢数据、可复现凭据泄露/注入、必要隐私或审核条件缺失。修复并验证前不提交。
- **重要**：关键流程错误处理、可访问性、权限拒绝后的使用障碍。根据实际影响判定是否升级阻塞。
- **建议**：不影响发布的界面润色、可选优化。可记入待办，不扩展为发布前重构。

不承诺审核必然通过。上游示例中的所有检查不自动成为 Apple 强制要求。

## 安全

- 密钥/令牌不硬编码于包、不明文写入普通偏好、不输出到日志。按平台采用适当安全存储；仅按用途检查随机数强度，普通 UI 随机数不需一律改造。
- 敏感网络传输验证 HTTPS/证书，检查广泛 ATS 例外、关闭 TLS 验证和不必要权限；合法 localhost 服务单独评估绑定地址、认证和来源控制。
- 输入进入 SQL、命令、文件路径、HTML、URL scheme 前有边界处理；参数化调用、防路径穿越与内容隔离符合实际威胁。
- Electron 额外检查 renderer 的 Node 能力、contextIsolation、preload/IPC 方法与 sender 校验、导航和外链白名单；依赖运行需要的 JIT 权限不能无依据删除。
- 检查 helper/extension/XPC、App Groups、Keychain groups 的身份与最小访问。MAS 和站外分发分别判断 hardened runtime/Developer ID/公证。

## 隐私和用户控制

按数据流检查本机/云端/第三方/AI/诊断日志的采集、用途、接收方、保存期、身份关联、追踪与删除方式。隐私 manifest 的 required-reason API 理由必须对应真实调用用途，不能复制通用理由代码。

系统权限在功能上下文申请，usage description 明确；拒绝和撤销后应用应给出可用的降级路径。需要追踪时核对 ATT；不追踪不为凑清单添加 ATT。涉及账号创建、第三方登录、删除账号、订阅或未成年人时按实际功能检查现行规则，不对无账号应用强行添加账号功能。

隐私政策、商店标签、应用同意界面、SDK/服务端行为须一致。卸载不一定删除 Keychain 或云端数据，不能宣称会自动清除一切。数据导出等建议按产品需求及适用要求判断。

## UX 与实际运行

干净环境首次启动、空数据、导入/保存、权限拒绝、网络断开、超时、重启与升级迁移都要覆盖相关核心路径。异步状态可理解且可恢复，错误不泄露内部私密内容。

检查键盘、VoiceOver、可读对比、不同窗口/屏幕或支持设备、长文本与本地化；依据实际障碍分级，不以固定 onboarding 页面或 tooltip 作为合规条件。

macOS 检查菜单栏应用如何打开窗口、设置与完全退出、文件选择及 sandbox 权限持久性；iOS 检查支持机型、方向、前后台和必要扩展行为。模拟器通过不证明设备特性通过；硬件相关流程应有实际设备证据或明确缺口。

## 分发

核验最终包（非仅源码）的身份、版本、证书链、profile、entitlements、图标、语言、SDK/最低 OS、权限用途和隐私清单。依赖许可与素材权利分别检查；不新增无需求的 analytics 或 crash SDK 来满足清单。

版本号按 Apple 当前格式和已有项目策略，不能硬性要求三段 SemVer。截图/图标尺寸以当前官方要求及目标设备为准；不要复制参考仓库的静态设备表。明确站外包与商店包，不能要求 MAS 同时做站外公证。

## 网络与后台

核验 401/403/429/5xx、超时、离线、登录态过期、刷新与缓存失效；重试有界并尊重 Retry-After，对写入考虑幂等。保持必要且脱敏的生产诊断日志，不一概禁止生产日志。User-Agent 的格式按服务契约判断，不把缺少自定义 UA 直接定为审核阻塞。

送审所需服务真实可用，审核账号可完成全部核心路径；服务故障不得靠隐藏或虚构功能规避。

## 输出与后续

沿用项目发布记录，列阻塞、证据、已修复及剩余建议。只审查请求不修改或提交；上架执行请求中继续完成范围内修复及必要回归。通过本审核仍需执行 ASC 验证、隐私发布核验、公网页面检查与最终目标确认。
