# 商店安装版 QA 与录屏

适用于首次上架、工程拒审整改以及涉及关键路径的更新。真机测试与 TestFlight 不是同一概念：TestFlight 是分发渠道，不是每次上架的强制前置；关键功能须有真实支持设备证据。Electron MAS 优先通过 TestFlight 核验 Apple 分发后的沙盒行为，不以无法直接运行发行签名包推断包损坏。

## 安装身份与取证

先验证本地最终产物，再依次核验：Apple 交付、处理、测试群组可用、实际安装、实机测试。处理延迟只查询具体阶段；复用已有群组/测试者，不重复邀请或上传。下载确实失败才按实际错误重试，不能靠重打包解决登录过期或界面缓存。

实机 QA 记录：安装渠道、实际路径或设备安装记录、Bundle ID、版本/构建、签名身份（如可查）、设备/OS、测试时间、结果、证据位置。Mac 可能同时有 `/Applications` 与用户 `Applications` 下的不同副本；核对运行进程实际路径和安装版 Info.plist，不用应用显示名称代替身份。不要覆盖或删除用户的开发副本。

记录已执行、失败、未测及不适用项，并说明原因；包哈希关联上传产物，安装身份关联实测对象，不要求 Apple 重签后的 app 哈希与上传包一致。记录或截图脱敏，私人原始日志、录像与凭据留在授权私有位置。

## 按功能挑选最小验证矩阵

| 场景 | 验证的结果 |
|---|---|
| 首次启动/升级 | 启动无崩溃；必要同意与权限可处理；已有数据与迁移正确；发布渠道的资源/文案正确 |
| 核心操作 | 用虚构样例完成输入、处理、保存及结果查看；不能以后台 health 200 代替 AI/导入等完整流程 |
| 文件/沙盒 | 用真实文件选择器导入适用格式，验证实际权限；不能只用开发目录直接读文件 |
| 账号/UGC/购买（如有） | 注册登录删除、内容管理、购买/恢复等按产品及当前规则实测；账号类型和地域限制覆盖审核路径 |
| 网络/模型（如有） | 首次下载与可用状态、真实推理/请求、超时离线和错误恢复；同意、接收方与隐私资料一致 |
| macOS 窗口 | 原生入口打开，红色关闭后重开，最小化后恢复，快捷键及无重复窗口 |
| 使用资源后退出 | 使用音频/推理/连接后执行真正 Quit，进程及应终止的 helper/端口结束，再启动核查持久化 |
| iOS/iPadOS 生命周期 | 支持设备与方向、前后台恢复、权限及关键硬件能力；见 [移动平台参考](ios-ipados.md) |

语音应用分开验证“麦克风授权 → 真实录音 → 模型下载/完整性 → 本地或远端识别 → 预览 → 保存”。输入文字替代语音仅验证下游文本流程；模型目录存在不证明可用；混入环境声音的合成播放不作为识别准确率证据。

权限弹窗未处理时，结合实际请求日志和界面状态判断等待、允许、拒绝或故障，不凭空白界面断言拒绝。系统受限授权、锁屏或双重认证按工具要求由用户完成，不能换工具绕过明确限制。用户确认后继续原检查点，不重做已有效完成的上传。必要的临时屏幕保持唤醒应有时限并在完成后结束，不改永久锁屏策略。

## macOS 退出与保存

先区分驻留设计、关闭窗口、最小化和真正 Quit。记录 Quit 前的目标 PID/子进程与监听，执行应用正常退出入口，再确认相关进程及端口停止；验证前不要调用会重新启动应用的工具，否则产生假结果。若后台 helper 按设计继续运行，核验其必要性、用户同意及可停止方式。

失败时收集触发路径、调用栈和资源释放证据，避免直接宣称具体原生库为根因。修复顺序依项目实现确定：阻止重复退出清理、持久化待保存数据、等待异步原生资源释放、关闭连接/定时器/快捷键、正常退出。若确需有界强制退出兜底，必须先完成数据与资源安全清理；清理失败或异步写入未完成不能假定安全。Chroni 的“清理完成后 5 秒兜底”是个案，不是通用阈值或默认模板。

修复后做正常退出和原故障触发路径回归，重新构建并实际安装。使用自己创建的可识别样例检查重启持久化；清理时按样例的唯一身份及关联记录删除，仅删除本次自己的数据，不清空用户账户、数据库或偏好。

## 审核录像

先读当次审核要求确定是否需要、所需设备/OS 和展示范围。用户要求代录时，直接使用可用的 QuickTime、系统录屏或受支持工具完成；已授权的录屏无需反复请求批准普通开始/停止步骤。先核验工具权限和目标窗口，不能把屏幕授权失败误报为录像完成。

1. 核对当前安装构建与画面，准备虚构数据，隐藏通知与无关私人窗口；错误资源或崩溃先修复，不继续拍旧包。
2. 录屏开始时应用未启动，按要求展示启动、核心流程及适用的账号/UGC/付费流程。涉及同意或模型下载时展示真实状态，可提前完成与本次展示无关的耗时准备并如实说明。
3. 使用可稳定停止并保存的方式；系统录屏命令参数先查看本机帮助，不写死历史参数。合理设置时长并确认实际进程结束、文件可播放。
4. 导出后检查时长、开头启动、关键流程和末尾，抽帧检查人物/资源及私人信息，播放关键片段；不能只验证文件非空。早停、黑屏、错误应用、私人画面或未完成流程的片段不上传。
5. 在审核私有附件或允许的访问渠道提交，明确文件名、版本/构建、设备/OS。验证附件或链接实际可用，并在回复与 Notes 引用。

复用旧录像仅作为**明确标注原版本/构建的通用流程参考**，本次修复另提供当前实机证据；不能称旧录像展示最新构建。Apple 指定最新录像、界面/核心流程发生变化或旧片段有缺陷时补录。没有新要求且旧材料仍适用时，不为每次更新重复录制。

## 完成条件

实际安装身份正确；必要场景已通过；失败与未测项按影响处理，无未解决发布阻塞；录像（若需要）已检查并可访问。之后才关联该构建正式送审，遵循 [状态判定](release-checks.md)。
